Design System PC

组件生成机制

在安能 PC 端中后台项目中，组件按来源分三层管理，项目中沉淀的私有组件可回流至 skill，供后续项目直接复用。

三层组件体系
LAYER 01
a-
Ant Design Vue
原生 UI 组件，直接使用，参考官方文档。覆盖通用场景：布局、表单、弹窗、数据展示等。
a-table a-form / a-form-item a-modal / a-drawer a-select / a-input
npm install ant-design-vue
LAYER 02
Anfe-
安能业务组件库
@anfe/vue-pro-components 封装的业务组件，内置请求、分页、表单 Schema 等能力，优先于裸 Ant Design 使用。
AnfeProTable AnfeBaseForm AnfeNavigationBar AnfeRegionCascader
npm install @anfe/vue-pro-components
LAYER 03
私有
项目私有组件
在项目实践中沉淀的本地组件，无法 npm 安装。通过规格文档 + 源码对齐，保证跨项目一致性。
FlowLog RejectCard FileUploadField FileAttachmentView
复制源码至 src/components/
📄
规格文档对齐
props、类型定义、用法示例、业务场景说明，保证使用方式一致。
⚙️
源码直接复用
存储经过审查的完整源码，生成新项目时原样写入，样式和交互像素级对齐。
私有组件回流机制
📋
项目需求
现有组件库无法满足的业务场景，需要定制开发。
→
🔨
开发私有组件
在项目 src/components/ 中创建，满足当前项目需求。
→
✅
质量审查
检查类型安全、默认值、样式一致性，修复潜在问题。
→
♻️
写回 skill
源码 + 规格文档写入 skill，后续项目直接生成，无需重写。
核心价值：每个新项目的组件积累不会丢失——经过审查的组件沉淀到 skill 后，下一个项目可以站在上一个项目的肩膀上出发，而不是从零开始。
已沉淀的私有组件
私有
FlowLog
流转日志时间线，按日期分组展示审批历史，支持 5 种操作类型、操作人、备注和附图。
建档 / 开工 / 完工详情页
私有
RejectCard
审核不通过卡片，支持单角色和多角色合并两种模式，可展开收起。
各节点申请页顶部
私有
FileUploadField
表单文件上传字段，支持选文件、删文件，已选列表展示文件类型图标。
各节点申请页表单
私有
FileAttachmentView
附件只读展示，鼠标悬停显示预览和下载操作，与 FileUploadField 成对使用。
各节点详情页附件区
私有
